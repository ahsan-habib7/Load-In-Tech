# 💻 Load-In-Tech

**Load-In-Tech** is a modern, responsive e-commerce website for premium computer hardware and gaming components.  
It’s built using **HTML**, **Tailwind CSS**, and **JavaScript** — designed for smooth UI interactions, elegant animations, and a clean hybrid color palette.

---

## 🌐 Live Demo

https://ahsan-habib7.github.io/Load-In-Tech/

---

## 🚀 Features

### 🛒 Core
- Responsive and modern **e-commerce layout**
- **Product categories** with dynamic filtering
- **Featured products** and **flash sales**
- **Gaming setup bundles** with price breakdowns

### 💬 User Experience
- **Interactive navigation bar**
- **Wishlist**, **Cart**, and **Compare** buttons with counters
- **Search functionality**
- **Sticky header** and smooth scrolling
- **Chatbot widget** with quick replies
- **Notification system** for cart updates

### 🧰 Additional Sections
- Flash sale timer with dynamic countdown
- Premium brand showcase
- Blog / Tech news & guides section
- Professional services (Assembly, Tuning, Warranty, Home Setup)
- Contact form and store details
- Newsletter subscription
- Customer testimonials
- Animated hero section with floating icons

---

## 🧱 Tech Stack

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Page structure |
| **Tailwind CSS** | Styling and responsive design |
| **JavaScript (ES6)** | Interactivity, dynamic components |
| **Custom CSS (LoadinTech.css)** | Extra UI adjustments |
| **Custom JS (LoadinTech.js)** | Handles filtering, chat, and cart logic |
